เลือกรูปแบบการติดตั้ง

เลือกรูปแบบที่เหมาะสมกับการใช้งานของคุณมากที่สุด

ติดตั้งบนคอมพิวเตอร์ (Standard PC)

เหมาะสำหรับการใช้งานประจำเครื่อง สร้างไอคอนทางลัดบน Desktop และเชื่อมต่อ Rich Presence สมบูรณ์แบบ

พกพาเต็มรูปแบบ (True USB Portable)

ไม่เขียนข้อมูลลง Windows Registry รันจาก Flash Drive ได้ทันทีโดยไม่ทิ้งร่องรอยในเครื่อง

เลือกโปรไฟล์สี Discord (1-12 บัญชี)

คลิกเลือกสีประจำตัวสำหรับแต่ละบัญชี ระบบจะสร้างไอคอนสีและแยกพื้นที่จัดเก็บข้อมูลให้โดยอัตโนมัติ
